Help & Guide

Adding a Country

Use Countries → Add Country to create a new record. Fill all fields and save.

Filtering & Search

Use the search box for quick searches by name, capital, currency or continent. Use the filter to limit by continent.

Import / Export

Use JSON export to download data. Import accepts JSON arrays of country records. Duplicate names are skipped.

Favorites

Use the star/fav button to bookmark countries; view them on the Favorites page.
